# 追加機能：実績入力・管理画面（管理者）
docs/ を踏まえ、管理者がキャストの実績をアプリ内で入力・編集できる画面を追加してください。
これによりExcel取込に依存せず、アプリを実績の正（source of truth）とします。

## 入力対象（キャスト×営業日 単位、04のattendances/sales/performance_countsに対応）
- 出勤：出勤/退勤 または 勤務時間、出勤区分（通常/同伴出勤）
- 指名系：本指名 本数 / 場内指名 本数 / 同伴 回数
- ドリンク 杯数 / ボトル・シャンパン 実績 / 延長 回数
- 売上：区分別（本指名売上/フリー売上など）金額

## UI
- 一覧（月選択→キャスト×日のグリッド）と、行クリックで日別の入力フォーム。
- 「日別入力」と「月まとめ入力」の両方に対応できると尚良い。
- 保存すると即、給与明細(payroll.ts)とランキング(ranking.ts)・ダッシュボードに反映。

## ルール
- 値は設定マスタ（08）の単価・率で計算に使われる。実績側に金額ロジックは持たせない。
- store_idスコープ。キャストは自分の実績を閲覧のみ（編集は管理者）。
- バリデーション（負値・時間の前後関係・空欄）。
- Excel取込は残すが「任意の一括投入」と位置づけ、手入力と同じテーブルに洗い替えで入る。

## seed/デモ
- SAKURAの実績を、当月給与が¥480,000・指名28本・同伴7回・出勤14日になるよう入れておく。

## 完了条件
- 設定画面で単価変更 → 実績入力 → キャスト給与明細とランキングが連動して変わる、を一連でデモできる。

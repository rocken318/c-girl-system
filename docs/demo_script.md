## 0:00-0:20 — ログイン画面
- ブラウザで表示。「高級ナイトラウンジをイメージしたUIです」
- admin / admin でログイン

## 0:20-0:50 — 管理者ダッシュボード
- KPIカード（売上・出勤・予約・申請）を指しながら概要説明
- キャスト別サマリを下にスクロール
- 「SAKURAさんの給与が¥480,000です」

## 0:50-1:20 — 設定画面（デモの目玉）
- 左メニュー「設定」→ 時給タブ
- 「SAKURAの時給を3000→3500に変えてみます」→ 保存
- ダッシュボードに戻る → SAKURAの給与が変わっていることを確認
- 「設定を変えるだけで全ての計算が連動します」

## 1:20-1:50 — 実績入力
- 左メニュー「実績入力」
- 日別グリッドを見せる：「Excelの代わりにここで入力します」
- セルをクリック → モーダルで日別実績を編集
- 右側の給与プレビューがリアルタイム更新

## 1:50-2:20 — キャスト側
- ログアウト → SAKURA / 1234 でログイン
- マイページ：給与カウントアップアニメーション
- 給与明細：全項目の内訳、PDF印刷ボタン
- ランキング：金銀銅メダル表示

## 2:20-2:50 — 権限分離
- 「キャストは自分のデータしか見えません」
- 設定画面や他キャストの給与へのアクセスができないことを説明
- URL直打ちでも管理者画面に入れないことをデモ

## 2:50-3:00 — まとめ
- 「紙・Excel・電話の業務をWebで一元化」
- 「設定はすべて画面から変更可能、ハードコード値ゼロ」

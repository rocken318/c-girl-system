# データモデル設計（ドラフト） — キャスト管理システム「金魚」

マルチ店舗を見据え、**全主要テーブルに `store_id` を保持**する。単価・率は**履歴を持つマスタ**として管理し、過去明細を不変に保つ。

## 1. 主要エンティティ概要

| テーブル | 役割 | 主なカラム（抜粋） |
|---|---|---|
| `stores` | 店舗 | id, name, 締め日, 支払日, 設定 |
| `users` | 管理者/キャスト/保守の認証主体 | id, store_id, role, login_name, password_hash, status, 2fa |
| `casts` | キャスト基本情報 | id, store_id, user_id, 源氏名, 本名(暗号化), 在籍状態, 入店日/退店日, ランク |
| `pay_rates` | 給与単価マスタ（履歴） | id, store_id, cast_id(任意), 時給, 各バック単価/率, 有効開始/終了日 |
| `attendances` | 出勤実績 | id, store_id, cast_id, 営業日, 出勤/退勤, 勤務時間, 区分(同伴出勤等) |
| `sales` | 売上実績 | id, store_id, cast_id, 営業日, 売上区分, 金額 |
| `performance_counts` | 指名/同伴/ドリンク等の本数 | id, store_id, cast_id, 営業日, 種別, 件数 |
| `import_batches` | Excel取込単位（冪等・洗替） | id, store_id, ファイル名, 取込日時, 対象期間, 状態, 取込者 |
| `payrolls` | 給与計算結果（確定スナップショット） | id, store_id, cast_id, 対象期間, 総支給, 控除, 差引支給, 状態(下書/確定) |
| `payroll_items` | 給与明細の項目内訳 | id, payroll_id, 項目種別, 数量, 単価, 金額 |
| `rankings` | ランキング集計結果 | id, store_id, 対象期間, 指標種別, cast_id, スコア, 順位, 公開フラグ |
| `reservations` | 予約 | id, store_id, cast_id(任意), 日時, 客名/メモ, 状態 |
| `requests` | 各種申請 | id, store_id, cast_id, 種別(欠勤/遅刻/同伴報告等), 内容, 状態(申請/承認/却下), 承認者 |
| `audit_logs` | 監査ログ | id, store_id, actor_user_id, 操作種別, 対象, 日時, IP |

## 2. リレーション（要点）

- `stores 1 — N users / casts / sales / ...`（全データは店舗にスコープ）
- `casts 1 — 1 users`（キャストはログイン主体に対応）
- `casts 1 — N attendances / sales / performance_counts / payrolls / requests`
- `import_batches 1 — N attendances / sales / performance_counts`（取込単位で洗い替え＝冪等性）
- `payrolls 1 — N payroll_items`（明細内訳）

## 3. 設計上の注意

- **横断アクセス禁止：** 全クエリは認証ユーザーの `store_id` でフィルタ。キャストはさらに自分の `cast_id` に限定。
- **冪等な取込：** 同一 `import_batches` 対象期間は再取込で洗い替え（重複加算を防ぐ）。
- **単価の履歴管理：** `pay_rates` は有効期間を持ち、給与計算は「対象期間時点の単価」を参照。
- **確定スナップショット：** `payrolls`/`payroll_items` は確定時の値を保存し、後のマスタ変更の影響を受けない。
- **機微情報：** 本名・連絡先など高機微項目は暗号化保存。`audit_logs` で閲覧も記録。
- **退店者：** `casts.status` で在籍/退店を管理。保持期間後に匿名化（方針は要確認）。

## 4. ER概要（テキスト）

```
stores ─┬─< users ──1:1── casts ─┬─< attendances ─┐
        │                        ├─< sales         ├─< (import_batches)
        ├─< pay_rates            ├─< performance_counts ┘
        ├─< rankings             ├─< payrolls ─< payroll_items
        ├─< reservations         └─< requests
        └─< audit_logs
```

# 給与計算仕様書（ドラフト） — キャスト管理システム「金魚」

> **本書は本システムの心臓部。** 提案書には計算式が無く、店側ヒアリング未実施のため、**ナイトクラブ/キャバクラの一般的な給与体系をベースにした仮モデル**を提示する。
> 数値・有無・端数処理はすべて **★要確認**。実際の運用ルール（できれば現行Excelの計算式）を入手して確定させること。
> 計算ロジックは設定（マスタ）で切替可能にし、店ごと・キャストごとに変えられる構造を前提とする。

## 0. 設計上の鉄則

1. 給与計算は**サーバー側の単一エンジン**で行い、画面やExcel関数に散らさない。
2. **再計算可能・監査可能**にする。確定後も「何をどう計算したか」の内訳を保存。
3. 単価・率は**マスタ管理**（コード埋め込み禁止）。期間で履歴を持つ（単価改定に対応）。
4. 確定＝スナップショット。確定後に単価を変えても過去明細は不変。
5. **マスタは管理者が画面（設定画面）から編集する**（A-10）。時給・各種客単価/バック単価・歩合率・控除・締め日/支払日・端数処理・ランキングpt定義を、開発者の手を借りずに店側が変更できること。固定値・定数での埋め込みは禁止。本仕様書の★（未確定値）は「設定画面で店が後から入れる項目」と読み替えてよい。

## 1. 給与の構成（一般的なモデル）

総支給 ＝ **基本給** ＋ **歩合（売上バック）** ＋ **各種バック** ＋ **手当** − **控除**

### 1.1 基本給（時給ベース）
- 時給 × 勤務時間。★時給はキャストごと（ランク制の場合あり）。
- 遅刻・早退・欠勤の扱い（控除 or 不支給）★要確認。
- 同伴出勤・本指名出勤での時給加算の有無 ★。

### 1.2 歩合（売上バック）
- 自分の売上に対する一定率のバック。★率（例：本指名売上の◯%、フリー売上の◯%）。
- スライド制（売上額に応じて率が変わる）の有無 ★。

### 1.3 各種バック（明細項目）
代表的なものを列挙。**有無・単価は要確認**。

| 項目 | 内容 | 単価/率（★仮） |
|---|---|---|
| 本指名バック | 本指名1本あたり | ★ 例 ¥1,000/本 |
| 場内指名バック | 場内指名1本あたり | ★ |
| 同伴バック | 同伴1回あたり | ★ 例 ¥1,500/回 |
| ドリンクバック | キャストドリンク1杯 | ★ 例 ¥300/杯 |
| ボトル/シャンパンバック | ボトル類の一定率 | ★ |
| 延長バック | 延長1回 | ★ |

> モックの「指名28本」「同伴7回」はこのバック算定の入力値に相当。

### 1.4 手当
- 皆勤手当・送り（タクシー）・交通費など ★有無を確認。

### 1.5 控除
| 項目 | 内容 | ★ |
|---|---|---|
| 罰金 | 遅刻・欠勤・規則違反など | 有無・金額 ★ |
| 厚生費/その他天引き | ヘアメイク・衣装・送り代等 | ★ |
| 前借り/日払い精算 | 日払い済み分を月給与から差引 | **重要・要確認** |
| 源泉徴収 | 報酬の源泉所得税 | **税務上の扱い＝要確認（雇用 or 業務委託で変わる）** |

## 2. 計算フロー

```
1. Excel取込 → 出勤・売上・指名/同伴/ドリンク等の実績を取り込む
2. 実績の検証（欠損・異常値チェック、取込バッチ単位で確定）
3. キャスト × 期間で集計
4. マスタ（時給・各単価・率・控除設定）を適用して各項目を算出
5. 総支給・控除・差引支給を計算（端数処理ルール適用）
6. 管理者が内容確認 → 「確定」 → 明細スナップショット保存・公開
7. キャストはマイページ/給与明細で本人分のみ閲覧
```

## 3. 計算式（疑似コード・仮モデル）

```
基本給        = 時給 × 勤務時間（時間は分単位で集計し最後に丸め）
歩合          = Σ(対象売上 × 区分別バック率)
本指名バック  = 本指名本数 × 本指名単価
同伴バック    = 同伴回数   × 同伴単価
ドリンクバック= ドリンク杯数 × ドリンク単価
…（その他バック同様）

総支給 = 基本給 + 歩合 + 各種バック合計 + 手当合計
控除   = 罰金 + その他天引き + 前借り精算 + 源泉徴収
差引支給 = 総支給 − 控除
```

- **端数処理**：円未満は ★切り捨て/四捨五入 を統一（要確認）。各項目で丸めるか最後にまとめて丸めるかを明確化。
- **計算期間**：締め日基準（モックに「締日まで残り12日」表記あり）。★締め日・支払日を確認。

## 4. 給与明細の表示要件

- キャスト：本人分のみ。総支給／各項目内訳／控除内訳／差引支給を明示。
- 管理者：全キャストの明細を一覧・個別確認、確定/未確定の状態管理、CSV/PDF出力（★出力要否確認）。
- 労基法上の必要記載事項を満たす（雇用形態による）。

## 5. ランキングとの関係

ランキングの「pt」が給与のどの値に対応するか未定義。候補：①売上、②指名本数、③独自ポイント（バック点数の合算）。
**給与計算とランキングは入力（実績）を共有するが、別ロジック**として実装する。★pt定義を確定すること。

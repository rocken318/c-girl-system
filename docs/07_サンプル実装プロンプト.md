# 07_サンプル実装プロンプト（Claude Code用）

提案書＋モックの現有資料で作る「動くサンプル（デモ用プロトタイプ）」の実装プロンプト。
**目玉：時給・各種客単価・バック単価・歩合率・控除などを管理者が設定画面で編集 → その値で給与計算が走る（マスタ駆動）。**
モデルはSonnet 1本でOK（量産中心）。出来上がり後、給与明細の精査だけOpusに任せると安全。

---

```
# 役割
あなたはフロントエンド実装担当です。NEW CLUB Kingyo（仙台・国分町）向けキャスト管理システムの
「動くサンプル（デモ用プロトタイプ）」を作ってください。docs/ 配下の各資料とUIモックを反映します。

# 重要な前提（割り切り）
- 顧客に見せるデモ。実DB・本番認証は作らない。データはフロント内（in-memory / React state）。
- ★最重要：時給・各種客単価・バック単価・歩合率・控除・締め日などの「数値」は一切ハードコードしない。
  全て【管理者の設定画面】で編集でき、その値を給与計算が参照する構造にする（マスタ駆動）。
- 構造は将来を見据え store_id を持たせる（表示は1店舗固定）。

# 技術
- React + TypeScript + Vite + Tailwind、react-router。`npm install && npm run dev` で起動。
- 状態管理は React Context 等でアプリ全体に「設定マスタ」を保持（localStorageは使わない）。

# 設定マスタ（管理者が画面で編集できる項目）— src/store/settings.ts に集約
以下を【管理者 > 設定】画面で追加・編集・保存でき、変更すると給与明細やダッシュボードに即反映:
- 時給設定：キャスト個人別（またはランク別）の時給。
- 各種単価/バック：本指名・場内指名・同伴・ドリンク・ボトル/シャンパン・延長 などの単価。
  （項目は固定リスト＋「行を追加」で店が独自項目を増やせると尚良い）
- 歩合率：売上区分別の率（スライドの有無は任意）。
- 控除設定：罰金・天引き・送り代などの項目と金額/率、前借り精算。
- 店舗設定：締め日・支払日、端数処理ルール（切捨/四捨五入・丸めタイミング）。
- ランキング設定：ptの定義（売上/指名本数/独自ポイント）と公開ON/OFF。
- 初期値はデモが成立する仮値をseedで入れておくが、あくまで画面から変更可能であること。

# 給与計算
- src/lib/payroll.ts に計算を集約。計算は必ず settings マスタを参照（固定値禁止）。
- 総支給 = 基本給(時給×時間) + 歩合 + 各種バック - 控除。設定変更で結果が変わることをデモで体感できる。

# ブランド/デザイン
- メインカラー #c8243e、白＋淡い水色グラデ＋波紋、金魚アイコン。
- 金額は特大(44px相当)・本文16px。キャスト=スマホファースト＋下部タブ(ホーム/ランキング/出勤/設定)。管理者=PC幅。

# 画面
## ログイン：名前＋PW。デモ用に admin と キャスト(SAKURA)。
## キャスト：マイページ（今月給与 / 出勤14日 / 指名28本 / 同伴7回、メニュー4枚、下部タブ）
## キャスト：給与明細（設定マスタ×実績から payroll.ts で算出した内訳・控除・差引支給）
## キャスト：出勤・売上履歴 / ランキング閲覧 / 各種申請（送信→申請中で一覧表示・モック動作）
## 管理者：ダッシュボード（当月売上¥8.4M / 本日出勤87 / 予約12件 / 未承認申請3件）
## 管理者：キャスト管理 / 申請承認(承認・却下) / ランキング管理
## 管理者：★設定（上記「設定マスタ」を編集する画面。本サンプルの目玉）

# データ（seed）
- 店舗1、キャスト3名(SAKURA/RIN/YUI)＋数名。仮の設定値で SAKURA の給与が ¥480,000 付近になるよう調整。
- ランキング 1 SAKURA 120pt / 2 RIN 98pt / 3 YUI 85pt。
- seed は src/data/seed.ts、設定マスタは src/store/settings.ts に分離。

# 権限の見せ方（デモでも守る）
- キャストは自分の数字だけ、他人の給与は見えない。設定画面は管理者のみ。

# 完了条件
- `npm install && npm run dev` で起動、admin/SAKURA で全画面を回遊できる。
- 【設定画面で時給やバック単価を変更 → キャストの給与明細が再計算されて変わる】ことを必ずデモできる。
- モックの主要数字が表示される。READMEに「デモであること」「設定マスタ駆動」「本実装への差し替え点」を明記。
```

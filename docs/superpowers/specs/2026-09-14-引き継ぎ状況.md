### 既知の技術的負債（無害だが要認識）
- ドメインテーブル(performances/daily_records/shifts/payrolls)と casts.user_id の **unique制約に store_id 無し**（単一店舗運用では無害、真のマルチ店舗運用前に要migration）。
- jsonbカラム(`data`)は未検証キャスト（型ドリフトでランタイム誤り得る）。
- lint：baseline ~26件の既存エラー（set-state-in-effect / react-refresh等、機能影響なし）。**ビルドゲートは `tsc -b && vite build`**。
- recharts でチャンク~1.4MB（将来 lazy import 候補）。
- `seed.sql`：db reset はマイグレーション→seedの順。**列追加のbackfillはmigration(本番用)＋seed(ローカル用)の二重**で入れる必要あり（0007/0013で対応済みの流儀）。

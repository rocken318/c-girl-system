## 1. 絶対原則（CLAUDE.md より・厳守）
1. **マスタ駆動**：時給/単価/率/控除/締め日/pt定義などの数値はコードに固定しない。設定(マスタ)から参照。
2. **権限分離**：キャストは自分のデータと公開ランキングのみ。他者の給与/本名/売上は不可（IDOR厳禁）。
3. **マルチ店舗前提**：全主要テーブルに `store_id`。クエリは所属店舗でスコープ。
4. **給与は単一エンジン**（payroll）に集約。確定はスナップショットで不変。
5. **★未確定値はハードコードしない**：仮値は seed/設定に置く。

## 3. 確定した設計方針（ヒアリング済み）
- **AIと個人情報 → 「店内匿名化」**：源氏名・集計値・給与額はAIに渡してよい。**本名・連絡先は渡さない**。匿名化レイヤをサーバー関数側に必須で置く。
- **AIプロバイダー → 従量・後払いで使える方を採用**。**前払いクレジット購入は避けたい**という要望あり。OpenAI/Claude いずれも、P5着手時に「前払い不要（従量後払い）で使えるプラン」を確認して確定（今は仮）。
- **系列店 → 既に複数運用中**。よって基盤(P0)から複数店前提でデータ投入・設計する（統合を後回しにしない）。
- **LINE → アラート通知＋「未提出督促」**：日報・シフト希望・出金予定などが未提出のとき、システムが検知し、**AIが督促文を生成してLINEでpush**する。LINEログイン連携は今回スコープ外。

## 4. アーキテクチャ
```
[React SPA / Vercel]
      │
      ▼
[Supabase] Postgres + RLS + Auth + RPC   ← 実績/勤怠/目標/店舗/申請
      │
[サーバー関数(Vercel or Supabase Edge)]  ← 鍵を使う処理は全部ここ
      ├─ AI API（匿名化した集計データのみ送信）
      └─ LINE Messaging API（push）＋ webhook
[定期実行(cron)] 未提出検知 → AIで督促文生成 → LINE push
```
原則：**AI/LINEのAPIキーは絶対にクライアントへ出さない（必ずサーバー関数経由）**。AIへは**匿名化後のデータのみ**。

## 5. 段階ロードマップ
| Phase | 内容 | 依存 |
|---|---|---|
| **P0 基盤** | `stores`マスタ正式化＋**複数店の実データ投入**（各店のキャスト/黒服名簿・給与条件）＋`user_store_memberships`＋「統合閲覧ロール」。既存の`store_1`固定クエリを店舗スコープ化 | 全ての前提 |
| **P1 目標＆達成率** | `sales_targets`（store_id・期間種別[day/month/quarter/half/year]・期間・目標額）＋`targets.ts`集計＋ダッシュボードに達成率バー。マスタ駆動 | P0 |
| **P2 補強** | ⑥出勤率％、③黒服別「担当合計売上」KPI | P0 |
| **P3 系列店統合** | 店舗切替＋全店合算ダッシュボード。RLSは統合ロールのみ横断許可 | P0/P1（優先度高＝既に複数店） |
| **P4 LINE＋未提出督促** | LINE公式アカウント、`line_links`(LINEユーザー↔アカウント)、webhook＆push関数、未提出検知cron。**日報・出金予定の提出モデル**を追加し、未提出→AI督促文→LINE push | P0 |
| **P5 AI分析** | 匿名化データで売上予測・キャスト個別分析。P4の督促文生成もこのエンジンを共用 | P0〜P3 |

## 6. 各Phaseの追加物（要点）
- **P0**：`stores`, `user_store_memberships`, 実データ移行スクリプト, 統合ロール, 既存クエリの店舗スコープ化。
- **P1**：`sales_targets`テーブル, `lib/targets.ts`, ダッシュボード達成率UI。
- **P2**：出勤率算出（出勤/予定 or 稼働）, 黒服別合計KPIカード。
- **P3**：統合ダッシュボード画面, RLSポリシー拡張（横断は統合ロールのみ）。
- **P4**：LINE Messaging設定, `line_links`, webhook/push関数, 未提出検知cron, `daily_reports`/`payout_requests`等の提出モデル。
- **P5**：匿名化レイヤ（本名→源氏名/匿名IDへ置換）, AI呼び出し関数, 分析画面。

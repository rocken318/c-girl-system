# 🐟 Kingyo キャスト管理システム — デモ版

> NEW CLUB Kingyo（仙台・国分町）向けキャスト管理デモプロトタイプ

## 概要
ナイトクラブのキャスト（ホステス）の出勤管理、給与計算、ランキングを一元管理するWebアプリ。
管理者の設定画面で時給・バック・歩合・控除を変更すると、給与明細がリアルタイムに再計算されます。

## デモ前提
- 本番DBなし（状態はブラウザメモリ、リロードでリセット）
- 認証は簡易（本番ではSupabase Auth等を想定）
- 5名のキャスト＋1管理者でシード済み

## 起動方法
```bash
cd app
npm install
npm run dev
```
http://localhost:5173 でアクセス

## 主要機能
### 管理者画面
- **ダッシュボード**: KPI（売上/出勤/予約/申請）＋キャスト別サマリ
- **キャスト管理**: 一覧・ステータス管理
- **実績入力**: 日別グリッド入力 ＋ 月まとめ入力（給与プレビュー付き）
- **給与確定**: 月次給与の確定・スナップショット保存
- **CSV取込**: テンプレートCSVで一括実績取込
- **申請管理**: 承認/却下
- **ランキング管理**: pt定義変更で集計切替
- **設定**: 時給/バック単価/歩合/控除/店舗/ランキングの全設定

### キャスト画面
- **マイページ**: 今月の給与（カウントアップ付き）＋統計
- **給与明細**: 全項目内訳 ＋ PDF印刷/CSVダウンロード
- **給与履歴**: 確定済み給与一覧
- **ランキング**: 順位＋pt表示
- **出勤履歴**: 日別の出勤・指名・ドリンク
- **申請**: 欠勤届・遅刻届・同伴報告等

## デモのポイント（設定→計算連動）
1. admin でログイン → 設定 → 時給タブ → SAKURAの時給を変更
2. ダッシュボード or 実績入力で給与が即座に変わることを確認
3. SAKURAでログイン → 給与明細で変更が反映されていることを確認
